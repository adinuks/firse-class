# Design

## The system
Use the `ui-design-system` skill for every screen. Black, white and one orange accent. Colours, type sizes, spacing and shapes come from the tokens. Never type a raw value in page CSS.

## My choices
- **Feeling in three words:** [calm, sharp, confident]
- **Accent colour:** orange (default). Change it only on purpose, and re-check contrast.
- **Voice of the words:** [plain and direct]
- **Theme:** light (default). Add `data-theme="dark"` for dark.

## Never
- A second accent colour.
- More than one primary button on a screen.
- Raw hex colours or pixel values in page CSS.
